# Security policy · Política de segurança

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Report them privately through
[GitHub's private vulnerability reporting](https://github.com/iM-lemoS/Clock/security/advisories/new)
(Security > Report a vulnerability). Include the app version, your Android version and the steps
to reproduce. You will get an answer as soon as possible, and credit in the fix if you want it.

Clock has no internet permission and no servers, so the relevant risks are on the device: other
apps abusing an exported component, data leaking through backups or notifications, or files
handled unsafely. Only the latest release receives fixes.

## Reportar uma vulnerabilidade

Por favor, **não abras uma issue pública** para problemas de segurança. Reporta-os em privado pelo
[reporte privado de vulnerabilidades do GitHub](https://github.com/iM-lemoS/Clock/security/advisories/new)
(Security > Report a vulnerability), com a versão da app, a versão do Android e os passos para
reproduzir. Respondemos o mais depressa possível, e ficas nos créditos da correção se quiseres.

O Clock não tem permissão de internet nem servidores, por isso os riscos relevantes estão no
dispositivo: outras apps a abusar de um componente exportado, dados a sair por cópias de segurança
ou notificações, ou ficheiros tratados de forma insegura. Só a última release recebe correções.
